# Static runtime generation

The editable native ESM source stays in `src/`. Published HTML uses generated,
content-hashed ESM entries and shared chunks. Vercel installs and builds nothing.
The isolated release tool pins esbuild 0.28.2 and ethers 6.15.0 exactly.

Install the tool from its own directory:

```sh
cd tools/runtime
npm ci
cd ../..
```

After changing runtime source, import query versions, or the vendor entry:

```sh
node tools/runtime/build.mjs
node tools/runtime/build.mjs --check
```

`--check` writes nothing. It rebuilds in memory and verifies generated bytes,
manifest, HTML, source fingerprints and approved compatibility assets. A release
includes the generated files and manifest together with the source change.

Generated runtime modules remain directly under `src/`, preserving existing
`import.meta.url` paths to `../tokens.json` and `../assets/`. WalletConnect, QR,
and chart vendors remain external dynamic imports. Early quote and UI entries
share the same service, clock and balance modules and their original deadlines.

The parser-time preload script selects only boot/app/common dependencies and the
current route's static closure. Swap does not preload the independent analysis
or pool modules. A hash change adds the next route's missing preload links; its
normal dynamic import uses the same module URLs and singleton instances. Unknown
hashes, including inherited object property names, fall back to the swap closure.

The six-export `ethers-entry.mjs` retains existing ABI, checksum and unit semantics
without provider or wallet classes. The manifest records package/source hashes
and the generated vendor's version and exports. HTML loads its immutable hash URL;
loader retries use the same small bundle at `ethers-6.15.0-fst.min.js`. This stable
fallback URL is deliberately mutable and must not receive immutable caching.
The original UMD and its published hash remain available to historical pages.

Complete licenses for packages that contribute output bytes are copied from the
pinned installed packages into `ethers-6.15.0-fst.LICENSE.txt`. The JavaScript footer
points to this notice. The manifest fingerprints the notice and the complete
original license sources; no external license text is fetched during a build.

The three stylesheet hash copies retain their exact source bytes and relative
font paths. Only content-addressed module, stylesheet and vendor URLs receive
immutable caching; editable source, fallback aliases and notices revalidate.

`compatibility.json` explicitly lists the actual previous release 49 and retained
releases 48, 47, 46 and 45, including source commit, frontend manifest hash and every approved
asset's SHA256 and length. The generator verifies and deduplicates this allowlist
before writing, rejects conflicting content, and removes only unapproved hashes
owned by this generator. Current HTML/preloads/imports contain only current assets.
Do not populate compatibility from an unpublished build or silently remove a
published cohort; deliberate removal needs a separate compatibility decision.
The allowlist is bounded to one previous release plus at most four retained releases.
